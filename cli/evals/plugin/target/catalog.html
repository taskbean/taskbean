Taskbean target eval catalog

Target behavior, draft for review. These cases describe where Taskbean should go. A gap is expected, not a regression. Release gates stay in npm run eval:plugin. Run this report with npm run eval:target from cli/.
Operating model. Taskbean reconciles outcomes with execution evidence for attribution, AI-value evidence, standups and leadership reports. Planner/To Do own commitments, owners, dates and assignments. Durable Priorities owns strategic outcomes. Copilot sessions and plan mode are execution evidence, not durable task storage.
